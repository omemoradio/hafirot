# חפירות ⛏️

משחק תרגול בלשון לכיתה ז׳, בעולם של קוביות. חופרים לעומק האדמה, ועונים על שאלות כדי לאסוף עפרות ולבנות מכושים.

נושאים: מילות הקישור, שם המספר (המספר המונה), תעודת הזהות של הטקסט, הבנת הנקרא.
בסוף מחכה "המבחן הנוראי", ומי שמנצח אותו מקבל תעודת הצטיינות.

לוח מעקב להורים: להוסיף `#parents` בסוף הקישור.
